# Grok "lessons" study (TEST MODE, not financial advice)
Grok cannot be fine-tuned, so the 2-year history is distilled into a lessons sheet + 24 real examples that ride in the prompt.
- lessons-train.md / examples-train.txt: built ONLY from Oct 2024-Jan 2026 (used for the held-out backtest).
- lessons-full.md / examples-full.txt: built from all 2 years (used by the TEST-MODE shadow module lessons_review).
- Backtest: 100 random days of Feb-Oct 2026 (held out), Grok 4.7 with vs without the sheet, live exit rules (+30% / -25% / 2 sessions, ask in, bid out, spread <= 10%, puts ETF/index only). Results: grok-lessons-results.json.
- Result: lessons arm +4.0 pts avg return, +4.4 pts win rate vs no-lessons, 95% day-bootstrap ranges -4.6..+12.6 and -4.1..+13.4 -> within noise. The gain came from 19 puts; on calls both arms are about the same.
- Wiring: lib/shadow/lessons-review.ts, enabled only with FLOWGUARD_LESSONS_TEST=1 (default OFF). Logs a shadow verdict (module lessons_review); never changes live picks, never sends Telegram.
- Scripts: scripts/study/grok-lessons-{dataset,examples,backtest,score}.py (data under /workspace/flowguard/study/grok-lessons-work).
- Week-2 update (Oct 17 2026): lessons-full.md reworks the ask/DTE bands from the 2-year rows (ask under $2 skip, $10-$30 no longer a pass reason, $30+ neutral; DTE 7-45 fine, 31-45 = 11-30, 0-6 untested, 46+ avoid; spread under 1% best) and adds live-week lessons (Oct 12-16). lessons-train-v2.md = same band changes on train-only numbers for a held-out re-test: `GROK_TEST_LEDGER=<new ledger> LLM_API_KEY=... python3 scripts/study/grok-lessons-backtest.py lessons_v2 study/grok-lessons/final-days.txt 3` then `python3 scripts/study/grok-lessons-score.py lessons_v2` (~$2.6 for 100 days at the old lessons-arm cost; not run yet, no key on the box).
- Weekly Friday refresh: `python3 scripts/study/grok-lessons-weekly.py` (after the Friday EOD study book, ~4:30 PM CT) regenerates weekly-lessons.md, weekly-stats.json, live-score.json and lib/shadow/grok-lessons-weekly.ts (the only file the site reads). Publish by committing those files. `--static` also rebuilds lib/shadow/grok-lessons.ts from lessons-full.md + examples-full.txt.
- live-score.json: lessons_review take/pass graded on the study book (scripts/study/grok-lessons-live-score.py; reads stored shadow days with readonly=1, no UW calls).
- Wide pool (Oct 18 2026, TEST MODE, FLOWGUARD_GROK_WIDE=1 + FLOWGUARD_LESSONS_TEST=1, default OFF): lib/shadow/wide-pool.ts sends Grok + lessons up to 200 extra candidates/day (FLOWGUARD_GROK_WIDE_MAX, max 1000; Oct 19: set to 500; tape fills ~365-495/day at ≤ 3 per issuer) taken from the session tape the live lists cut: tier "pool" = passes the Picks filters but ranks below the caps; tier "near-miss" = score 45-54 (≤ 1/3 of a run). Spread ≤ 10%, ≤ 3 per issuer/day, today's live finalists excluded. Own doc (GET /api/shadow?wide=1&day=...), own Grok ledger + cap (FLOWGUARD_GROK_WIDE_USD, default $1, max $3), rides /api/shadow/tick 10:00-14:30 ET (≥ 45 min apart, ≤ 100/run, batches of 20). 0 flow calls; grading = 1 UW historic per candidate after the 2-session time stop (live exit rules on daily bars). Scored per tier by scripts/study/grok-wide-score.py; never mixed with lessons_review on the finalists.
- Wide-pool held-out backtest (scripts/study/grok-wide-backtest.py, all 170 test days Feb 2-Oct 6 2026, pool rank 13-80, spread ≤ 10%, train-only sheet): 4,308 candidates, 320 takes. Takes 46.6% win / +3.14% avg vs passes 42.2% / -3.28%; avg gap +6.4 pts (day bootstrap 95% +1.5..+11.1, shuffle p=0.003), win gap +4.3 pts (-1.9..+10.5, p=0.07). Mostly ETF/index puts (63 takes, 55.6% / +10.5%); calls alone: no win-rate edge (44.4% vs 44.3%), avg gap -2.1..+7.7 range. $6.62 for 318 batches. Results: wide-backtest-2026-10-18.json.
